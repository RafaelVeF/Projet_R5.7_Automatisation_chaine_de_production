# Projet_R5.7_Automatisation_chaine_de_production
Ce monorepo contient l'ensemble des microservices (IHM, Ambassadeur Python, DataAccess C# et base de données) dédiés à la simulation d'une chaîne de production et de gestion de stocks. Il regroupe le code, les dépendances et la configuration Docker nécessaires au déploiement complet de l'architecture.
